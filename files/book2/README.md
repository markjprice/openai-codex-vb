# Book 2 sample files – Building and Publishing Websites

Copy the files you need into your `puzzle-pocket-website` folder inside
`Documents/Codex Projects`. Don't work inside your downloaded copy of this
repository.

| Chapter | Folder | What's inside |
| --- | --- | --- |
| 2.1 | `chapter01` | `PRODUCT-BRIEF.md`, a complete website brief, and `AGENTS.md`, working agreements for a website project |
| 2.2 | `chapter02` | `content/site-text.md` (text for every page), `content/ATTRIBUTIONS.md`, and `assets/` with the Atkinson Hyperlegible font and Lucide icons, each with its license. `example-mockups/` holds three finished mockups, in case you'd like to compare with yours or skip ahead |
| 2.3 | `chapter03` | `home-page-instruction.txt`, the four-part instruction, ready to paste |
| 2.4 | `chapter04` | `design-tokens.json`, a complete set of tokens for Puzzle Pocket |
| 2.5 | `chapter05` | `pages-plan-instruction.txt`, the planning instruction, ready to paste |
| 2.6 | `chapter06` | `accessibility-checklist.md`, the checks to tick off for each page |
| 2.7 | `chapter07` | `test-positions.md`, ten board positions to turn into tests |
| 2.8 | `chapter08` | `support-faq.md` and `privacy-policy-outline.md` |
| 2.9 | `chapter09` | `TESTING.md`, every requirement mapped to its checks |
| 2.10 | `chapter10` | `STORE-INFO.md`, a template for the app store URLs |
| All | `finished/puzzle-pocket-website` | The complete website from the end of Book 2, with unit tests, browser tests, and an accessibility scan |

## Notes

- Copy `example-mockups/*.svg` into `assets/mockups` only if you want to skip
  asking Codex for mockups in Chapter 2.2.
- The `finished` project needs `npm install` before it runs. See its README.
- The email address `hello@puzzlepocket.example` is a placeholder. Domains
  ending in `.example` can never be registered, so it can't reach anyone by
  accident. Use your own support address before you publish.
