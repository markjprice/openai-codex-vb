# Book 1 sample files – Getting Started with OpenAI Codex

Copy the folders you need into your `Documents/Codex Projects` folder.
Don't work inside your downloaded copy of this repository.

| Chapter | Folder | What's inside |
| --- | --- | --- |
| 1.1 | `chapter01` | `codex-loop-session.txt`, the fictional Codex session to label, and `codex-loop-session-answers.txt` |
| 1.2 | `chapter02` | `my-first-product-template.md`, a worksheet for choosing your first product |
| 1.3 | – | No sample files. Codex creates `README.md` for you. |
| 1.4 | `chapter04/recipe-scaler` | The complete Recipe Scaler project. Run `npm install` (or ask Codex to) before `npm test`. |
| 1.5 | `chapter05` | `PRODUCT-BRIEF-template.md` and `bill-splitter/PRODUCT-BRIEF.md` |
| 1.6 | `chapter06` | `AGENTS.md` and `instruction-template.txt` |
| 1.7 | `chapter07` | `TASKS.md` for the Bill Splitter |
| 1.6–1.9 | `bill-splitter-checkpoints` | The Bill Splitter after each task, in case you need to catch up |
| 1.10 | `chapter10` | `PRODUCT-BRIEF.md`, `TASKS.md`, and `AGENTS.md` for Guess My Number, and a `finished` folder with the complete game |

All the projects need Node.js (the LTS version). Only Recipe Scaler uses a
package; the others use Node.js built-in features only.
